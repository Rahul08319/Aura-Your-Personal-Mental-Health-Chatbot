## 🌟 Key Features

### 1. 🧠 Dual-Engine Empathetic Chatbot
- **Cloud Intelligence**: Direct streaming integration with Google’s `gemini-2.5-flash` model for nuanced, context-aware, empathetic listening and CBT reframing.
- **On-Device Private Companion**: If an API key is not configured or network drops, Aura seamlessly falls back to a built-in on-device compassionate engine with grounding techniques, stress relief guides, and reflection prompts. **Zero blank screens or unhandled errors.**
- **Speech-to-Text Support**: Speak your mind freely using the Web Speech API with animated pulse-ring voice feedback.

### 2. 🧘 Apple Watch-Inspired Breathing Meditation
- Visual, blooming petal iris animation with concentric translucent layers that dynamically expand during inhalation and contract during exhalation.
- **Scientific Breathing Modes**:
  - **Box Breathing (4-4-4-4)**: Focus and acute stress reduction.
  - **4-7-8 Relaxation Breath**: Vagal tone activation and sleep preparation.
  - **Resonant Breathing (5-5)**: Heart-rate variability coherence.
- Built-in soothing ambient bells synthesized on-the-fly using the browser's Web Audio API (432Hz harmonic scale) with zero external audio latency.

### 3. 📊 State of Mind & Mood Rhythm Tracker
- Modeled after Apple Health’s **State of Mind** experience.
- Track feelings from Happy and Content to Low and Anxious using semantic pastel accents.
- Dynamic gradient pillars display your check-in history, time stamps, and emotional trends.

### 4. 🌧️ Soundscape Studio with Live Waveforms
- High-fidelity looping audio: **Gentle Rain**, **Ocean Waves**, and **Serene Piano**.
- Live 4-bar equalizer waveforms that jump in sync with playback.
- Fine-tuned volume control with percentage readouts.

### 5. 🆘 Dignified Crisis SOS Card
- Instant one-touch connection to the **988 Suicide & Crisis Lifeline** and **741741 Crisis Text Line**.
- Expandable international directory covering the UK (111), Canada (988), India (Tele-MANAS 14416), and global support hotlines.

### 6. 🔄 Automated Future Continuity (Auto-Updating Years)
- **UI Logic**: Dynamic year interpolation (`© 2025–${new Date().getFullYear()}`) across the application, timelines, and footer metadata.
- **CI/CD Automation**: Scheduled GitHub Actions workflow (`auto-update-and-healthcheck.yml`) configured with cron schedules (weekly and on every Jan 1st) to verify builds, dependencies, and operational integrity for years to come.

## 🚀 Getting Started

### Prerequisites
- **Node.js** (v18.0 or higher)
- **npm** or **pnpm**

### 1. Clone the Repository
```bash
git clone https://github.com/Rahul08319/Aura-Your-Personal-Mental-Health-Chatbot.git
cd Aura-Your-Personal-Mental-Health-Chatbot
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Configure API Key (Optional)
Aura works out-of-the-box in **Private Local Companion Mode**. To enable Google Gemini cloud streaming:

Create a `.env.local` file in the project root:
```env
GEMINI_API_KEY=your_gemini_api_key_here
```
*Alternatively, you can tap the ⚙️ Settings icon in the app header and paste your key directly into the secure browser storage.*

### 4. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 5. Build for Production
```bash
npm run build
npm run preview
```

## 🔬 TypeSafe AI Architectural Evaluation

As part of the continuous architectural evaluation using TypeSafe System One paradigms:

### 1. Choice Primitive for Tool Categorization vs. Compaction Accuracy
- **Recommendation**: Adding a **Choice** primitive for tool categorization significantly improves compaction and routing accuracy. In TypeSafe's System One (Jev), a `Choice` primitive evaluates a mutually exclusive set of candidate labels (e.g., `["breathing_exercise", "cbt_reframing", "ambient_sound", "crisis_escalation", "general_conversation"]`) and outputs a calibrated probability distribution across candidates.
- **Why this boosts accuracy**: When tool routing relies on freeform LLM generation, token overhead and hallucination risk increase. By decomposing routing into a System One `Choice` judgment, the prompt-and-parse phase is replaced by typed probability-weighted decision logic. This yields:
  - 100% deterministic type safety.
  - Sub-50ms routing latency.
  - Transparent confidence thresholds (e.g., escalating to crisis protocols if `crisis_escalation` probability exceeds 0.25).

### 2. Prompting Best Practices Analysis
- Instructions adhere to TypeSafe System One best practices:
  - Narrow, atomic judgments rather than multi-step narrative generation.
  - Criteria definitions are isolated from instructions.
  - Edge cases (such as ambiguous inputs or crisis signals) have explicit, non-overlapping evaluation criteria.
